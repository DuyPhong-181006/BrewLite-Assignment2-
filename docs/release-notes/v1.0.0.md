# BrewLite v1.0.0 – Release notes

**Ngày phát hành:** 21/11/2026 · **Tag:** `v1.0.0` · **Image:** `ghcr.io/duyphong-181006/brewlite-api:<sha của tag>`, `ghcr.io/duyphong-181006/brewlite-web:<sha của tag>`

## Vận hành

- `GET /health` trả trạng thái CSDL và commit SHA đang chạy.
- Docker Compose chạy đủ web + API + CSDL ở local bằng 1 lệnh.
- CI (lint, unit test, build, integration test), E2E Playwright, CD tự động với smoke test và rollback.
- Production chính trên AWS EC2: Docker Compose (Caddy + web + API + PostgreSQL), HTTPS tự động, CD deploy bằng SSH (ADR-007). Bản phụ trên Render + Vercel.

## Thay đổi CSDL

- Migration `init`: toàn bộ bảng (Product, SizeOption, Topping, User, Order, OrderItem, Payment, Promotion, LoyaltyTransaction).

## Hạn chế đã biết

- Màn quầy dùng 1 mã nhân viên chung (`STAFF_KEY`), chưa có tài khoản riêng cho từng nhân viên.
- Chưa dùng điểm thưởng để trừ tiền (loại `REDEEM` đã có trong CSDL).
- Chưa chạy offline (chưa có service worker).
- API trên gói Free của Render ngủ sau 15 phút, lần mở đầu chậm ~1 phút.

## Kiểm thử của bản này

- Unit test API: health, products, promotions, loyalty, state machine, payments, quầy pha chế (UNIT-T01 → UNIT-T17).
- Test web: ProductCard, màn menu 3 trạng thái, giỏ hàng (UI-T01 → UI-T04, UNIT-T04 → UNIT-T07).
- Integration test: INT-T01 → INT-T06, API-T01, API-T02.
- E2E: E2E-T01 trên cấu hình laptop và điện thoại.
